# 📌 Smart Agenda App

Smart Agenda, Java Swing ve MySQL kullanılarak geliştirilmiş masaüstü tabanlı bir ajanda ve etkinlik yönetim uygulamasıdır. Kullanıcıların günlük planlarını ve etkinliklerini düzenli bir şekilde takip etmelerini sağlar.

## 🚀 Özellikler
* **Kullanıcı Yönetimi:** Güvenli giriş ekranı.
* **Etkinlik Takibi:** Günlük ve haftalık ajanda yönetimi.
* **Tarih Seçici:** `JCalendar` entegrasyonu ile kolay tarih seçimi.
* **Veritabanı Entegrasyonu:** Verilerin MySQL üzerinde güvenli ve kalıcı olarak saklanması.

## 🛠️ Kullanılan Teknolojiler
* **Dil:** Java (JDK 17+)
* **Arayüz (GUI):** Java Swing, JCalendar
* **Veritabanı:** MySQL
